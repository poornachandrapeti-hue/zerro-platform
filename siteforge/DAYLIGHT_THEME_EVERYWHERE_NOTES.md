# Daylight Theme Everywhere Update

This package extends the approved daylight banner theme to the remaining dark areas of the UI.

## Applied improvements
- Internal workspace sidebar changed from dark shell to light daylight panel styling.
- Partner portal shell and sidebar region now follow the same daylight theme.
- Home + partner wrappers remain visually consistent with the approved welcome banner.
- Navigation items remain readable, with a clear blue active state.
- Working cards, forms, and tables remain light and readable.

## Files changed
- `frontend/src/style.css`
- `frontend/src/home/design.css`

## Scope
Visual/theme only. No backend, RBAC, import, or database logic changed.
