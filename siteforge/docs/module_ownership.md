# Ownership decisions

| Concern | Owner | Consumers |
| --- | --- | --- |
| Contract agreements, BOQ/rates and terms | Contracts | Procurement, Financials, Planning |
| Budgets, bill certification and payments | Financials | Progress, PM |
| Purchase orders and supplier commitments | Procurement | Stores, Planning |
| Receipts, reservations, issues and stock | Stores | Procurement, Construction |
| Personnel, attendance and deployment | HR | Manpower, HSE, QA |
| Demand, crews and activity allocation | Manpower | Construction, Planning |
| Executed/verified quantity | Construction | Planning, Progress, Billing |
| Accepted quantity and quality holds | Quality | Construction, Stores, Billing |
| Permits and safety holds | Safety | Construction, Commissioning |
| Schedule and baseline | Planning | All execution owners |
| Published progress reports | Progress | PM, authorized Client |
| File revisions and dispatch evidence | Document Control | Engineering, Contracts, all modules |
| Request intake | Requests | Receiving domain owns fulfillment |

Requirements drafted earlier overlap. These decisions supersede duplicate ownership. There must be one authoritative stock ledger, attendance record, contract term version and quality outcome.

Lead PM assignment in the foundation creates a project membership. Former PM memberships remain until explicit access review. Commercial fields are not included in foundation APIs at all.
