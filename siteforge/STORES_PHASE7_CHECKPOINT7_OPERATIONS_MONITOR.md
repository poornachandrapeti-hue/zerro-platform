# Phase 7 Checkpoint 7 — Operations Monitor and Command Center Source Feed

Added `backend/app/domains/stores_inventory/phase7_monitor.py` and mounted its router. Provides a read-only, project/org scoped operational summary across preservation plans, cycle counts, stock adjustment reviews, and scrap cases. Source feed requires existing `X-ZerroR-Service-Key`; separate Command Center backend must authorize the viewer's actual project before displaying it. Each workflow scans the latest 500 records; counts are bounded and not comprehensive historical totals. Unplanned preservation lots are explicitly `unknown` rather than counted as zero. The Internal Stores screen now has a Phase 7 Operations tab with summary, exception details, freshness and limitations.

**Explicit limitations:** These records do not establish lot-level verified stock. Source feed does not mean the separate Command Center is deployed or connected. Existing legacy and transfer-derived issue hold gaps remain. Physical stock adjustment, disposal write-off, transfer posting and issuing flags remain disabled. No database schema changes in this checkpoint. PostgreSQL, frontend build, Docker and notification-worker integration are deferred. Run `python -m pytest -q tests/test_stores_phase7_operations_monitor.py` from backend for focused tests.
